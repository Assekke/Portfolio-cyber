# Подсветка портфолио по позиции Dota 2

## Для кого и зачем

Тот, кто ищет игрока, сможет быстро различать выбранную позицию по цвету подходящих портфолио.

## Что должно быть

- При выборе позиции в фильтре подходящие портфолио в списке игроков подсвечиваются цветом выбранной позиции. Учитываются основная и дополнительные роли.
- Позиция 1, Кэрри — тёмно-красный `#A92B39`; позиция 2, Мидер — оранжевый `#E99A45`; позиция 3, Оффлейнер — фиолетовый `#A77AE3`; позиция 4, Саппорт — голубой `#55A9D8`; позиция 5, Полная поддержка — зелёный `#69B985`. Заливка заметна на фоне обычных кнопок.
- При выборе «Все роли» каждый игрок Dota 2 подсвечивается цветом своей основной роли. Если роль не указана, нестандартная или игра другая, используется обычное оформление. Цвет не заменяет название роли и не меняет сохранённое оформление портфолио.
- Подсветка обновляется при смене фильтра. Переход в портфолио и сообщение об отсутствии игроков продолжают работать.

## Примеры

1. У Storm основная роль «Мидер», дополнительная — «Саппорт». При выборе «Мидер» Storm подсвечивается оранжевым, при выборе «Саппорт» — голубым.
2. При выборе «Все роли» Storm подсвечен оранжевым по основной роли «Мидер»; портфолио с другими играми остаются доступны без подсветки позиции.
3. Если подходящих игроков нет, показано сообщение об отсутствии результатов.

## Ограничения

- Только HTML, CSS и JavaScript; данные остаются в localStorage. Внешние ресурсы не используются.
- Сохранённые данные и настройки оформления не меняются из-за выбора фильтра.
- Названия игроков читаемы в светлой и тёмной темах, управление доступно с клавиатуры и на ширине 375 px.
- Ранее согласованный светло-красный цвет остальных кнопок и списков сохраняется.

## Готово, когда

- Все пять позиций показывают согласованные цвета для подходящих игроков по основной и дополнительной роли.
- Смена фильтра, «Все роли», пустые результаты, переключение портфолио и F5 работают.
- Старые портфолио доступны; изменения не влияют на сохранённые настройки и PDF.
- Проверены обе темы, клавиатура и ширина 375 px; README описывает подсветку и её проверку.
