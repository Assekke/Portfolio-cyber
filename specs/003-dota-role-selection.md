# Выбор позиции Dota 2

## Для кого и зачем

Игрок выбирает основную позицию Dota 2 из списка вместо ручного ввода в поле «Роль» основного портфолио.

## Что должно быть

- Для дисциплины Dota 2 (включая Dota2, «Дота 2» и разный регистр) доступны пять позиций: Кэрри, Мидер, Оффлейнер, Саппорт, Полная поддержка. В списке указаны номера позиций от 1 до 5.
- Пока дисциплина пустая, также показан этот список. Пустой вариант «Не указана» сохраняет необязательность роли; позиция автоматически не выбирается.
- Для других игр остаётся прежний ручной ввод роли. При смене дисциплины введённая роль сохраняется, пока пользователь сам её не изменит.
- Старое значение вне списка отображается как сохранённая роль и сохраняется без изменений. Оно не становится ещё одной стандартной позицией: после выбора одной из пяти позиций старый пункт недоступен для повторного выбора.
- Выбранная роль сохраняется, восстанавливается после F5, отображается в просмотре и PDF и учитывается в предупреждении о несохранённых изменениях.

## Примеры

1. Ввести Storm, выбрать Dota 2 и роль «Кэрри — позиция 1», указать достижение, сохранить и нажать F5: роль «Кэрри» остаётся.
2. Выбрать «Мидер — позиция 2», затем «Полная поддержка — позиция 5»: видна выбранная позиция, после сохранения в просмотре отображается её название.
3. Открыть прежнее портфолио Dota 2 с ролью «Капитан»: прежнее значение видно и не меняется при сохранении других полей. Выбрать «Саппорт — позиция 4» и сохранить — роль меняется по выбору пользователя.
4. В портфолио Counter-Strike 2 ввести «Снайпер»: ручной ввод и сохранение продолжают работать. Поменять дисциплину на Dota 2 и обратно: текст роли не теряется.

## Ограничения

- Только HTML, CSS и JavaScript, без библиотек и сетевых запросов.
- Меняется только основное поле роли; роль участия в команде остаётся текстовой.
- Данные хранятся в прежнем формате localStorage. Старые портфолио не переписываются при открытии.
- Поле доступно с клавиатуры, не ниже 44px; на ширине 375px нет горизонтальной прокрутки.

## Готово, когда

1. В Dota 2 можно выбрать все пять согласованных позиций, ручного ввода новых значений нет.
2. Пустая роль, прежние нестандартные роли, роли других игр и смена дисциплины не приводят к потере данных.
3. Сохранение, F5, переключение портфолио и отмена перехода работают; в просмотре и печатном представлении видна сохранённая роль.
4. Исходный сценарий Storm → роль → достижение → сохранить → F5, управление клавиатурой и ширина 375px проверены.
