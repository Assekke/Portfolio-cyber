# Портфолио киберспортсмена

Откройте `index.html` двойным щелчком. Установка и интернет не нужны.

Страница позволяет указать никнейм, дисциплину (например, Dota 2), роль, статистику, достижения и контакты. После нажатия «Сохранить» появляется портфолио. Обязателен только никнейм; пустые разделы показывают «Не указано». Кнопка «Редактировать» возвращает к заполненной форме.

Данные хранятся в localStorage этого браузера и восстанавливаются после F5. Они не отправляются в интернет. Очистка данных браузера удаляет портфолио. Для доступа к нему используйте тот же браузер и тот же путь к файлу. Если браузер ограничивает localStorage для локальных файлов, разрешите локальное хранение или откройте файл в браузере, который его поддерживает.

## Как проверить

1. Откройте `index.html`. Введите Storm, Dota 2, Кэрри, 20 матчей, 1-е место на школьном турнире и storm@example.com. Это тестовые данные. Нажмите «Сохранить»: все шесть значений должны появиться в портфолио.
2. Нажмите F5: все данные должны остаться на месте.
3. Нажмите «Редактировать». Оставьте только Storm, роль и достижение. Сохраните: остальные разделы должны показывать «Не указано».
4. Введите несколько строк в статистику, достижения и контакты. После сохранения и F5 переносы должны сохраниться.
5. Попробуйте сохранить пустой никнейм или одни пробелы: появится «Введите никнейм», сохранения не произойдёт.
6. Введите `<script>alert(1)</script>` в текстовое поле: после сохранения виден буквальный текст, окно alert не появляется.
7. Проверьте ширину окна 375px: нет горизонтальной прокрутки, все элементы доступны, поля и кнопки не ниже 44px.
8. В инструментах разработчика временно подмените `Storage.prototype.setItem` функцией, выбрасывающей ошибку, и попробуйте сохранить. Должна появиться ошибка без подтверждения успеха, введённые значения остаются в форме. Обновите страницу для отмены подмены.
9. При повреждённой записи `esports-player-portfolio-v1` в localStorage появляется сообщение об ошибке чтения и доступна форма для повторного заполнения.

Даты вводятся в формате ДД.ММ.ГГГГ. Никнеймы и текст сохраняются в исходном написании. Статистика и достижения автоматически не создаются.

Требования: [specs/001-player-portfolio.md](specs/001-player-portfolio.md).
